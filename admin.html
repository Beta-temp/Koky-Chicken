How to publish: press Download menu.json → on GitHub open data/menu.json → Upload / replace the file → commit. The site updates in about a minute. Your edits are also kept as a draft in this browser until you press “Load menu.json” or “Start empty”. Item photos: put the image file in img/dishes/ and type its path (e.g. img/dishes/my-dish.jpg). Modifier groups (sauce type, Regular/Spicy…) are preserved as they are; to add a new group, edit the modifiers block in the JSON.
